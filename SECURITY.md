# Journey Planner v3: Security & AI Stability Audit

## 🛡️ Security Measures

### 1. XSS Hardening (Implemented 2026-05-15)
- **Problem**: The application was using `.innerHTML` to render text generated by external AI services (Gemini) and Google Places data. This posed a high risk of cross-site scripting (XSS).
- **Fix**: Replaced all instances of `.innerHTML` with secure DOM manipulation using `document.createElement` and `textContent`.
- **Files Affected**: `ui/map.js`, `ui/timeline/timelineCard.js`.

### 2. API Key Management (Current Risk)
- **Problem**: API Keys for Google Maps and Gemini are stored in `.env` and bundled in the client-side code.
- **Status**: **ACTIVE RISK**.
- **Mitigation**: Keys are currently restricted by domain/referral in the Google/AI Cloud Console.
- **Future Work**: Plan for Phase 4 to move all API calls to a secure backend proxy (Firebase Cloud Functions).

### 3. Local Storage Privacy
- **Problem**: Journey data is stored in `localStorage` in plain JSON.
- **Status**: **LOW RISK** (Non-sensitive data).
- **Future Work**: Implement encryption for sensitive metadata if the app adds "Notes" or "Photos" features.

## 🧠 AI Stability & Drift Management

### 1. Robust JSON Parsing (Implemented 2026-05-15)
- **Problem**: Gemini AI occasionally adds conversational text (drift) or markdown blocks around its JSON responses, causing `JSON.parse` to fail.
- **Fix**: Implemented `parseAIResponse` in `VibeEngine` which uses regular expressions and index-based slicing to extract valid JSON even when surrounded by conversational text.
- **Files Affected**: `services/engine.js`.

### 2. Hallucination Guardrails (Implemented 2026-05-15)
- **Problem**: AI might suggest non-existent places or locations that are closed.
- **Fix**: Implemented a **Double-Grounding Pipeline**.
  1. AI acts only as a keyword strategist.
  2. Google Places API performs the actual physical search.
  3. App filters results for `business_status: 'OPERATIONAL'`.
- **Files Affected**: `services/discoveryEngine.js`.

### 3. Response Timeout & Fallback
- **Problem**: API latency can cause the UI to hang.
- **Fix**: Standardized on a **5-second timeout** for all AI calls with graceful fallback to local, high-quality "safe-bet" data.
- **Files Affected**: `services/engine.js`.

---

## 🐞 Performance & Reliability

### 1. Memory Leak Prevention
- **Fix**: Explicitly clearing Google Maps event listeners and markers during Discovery Radar scans to prevent browser memory bloat.
- **Files Affected**: `ui/map.js`.

### 2. Map Resize Logic
- **Fix**: Implemented automatic resize triggers on view transitions to prevent the "Google Maps Sliver" bug.
- **Files Affected**: `ui/map.js`, `core/viewOrchestrator.js`.
